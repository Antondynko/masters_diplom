# VND-алгоритм поиска радиуса пороговой устойчивости

Двухуровневая задача размещения предприятий с предпочтениями клиентов. Основан на VND-эвристике и локальному спуску.

Python 3.10+, только стандартная библиотека.

## Быстрый старт

```bash
python main.py
```

По умолчанию: датасет `datasets/20_20_15.txt`, `V=47000`, `p=15`. На stdout — матрицы радиусов устойчивости и `Elapsed time`.

Мультистарт - независимые запуски из разных случайных стартов параллельно по процессам:

```bash
python main.py --starts 32 --seed 1            # процессов = число ядер
python main.py --starts 32 --workers 4 --seed 1
```

Выводит результат каждого старта и сводку: лучшее, худшее, среднее ± разброс. При одном `--seed` результат не зависит от `--workers`. Из кода: `vnd.parallel.solve_multistart(...)` возвращает `MultistartResult` (`best`, `runs`, `summary()`).

Остановка: `Ctrl+C`. Для больших датасетов (80+80, 100+100) запуск может занять несколько минут.

## Формат датасетов

Файл: `{n}_{m}_{median}.txt`. Первые 3 строки — заголовок (пропускаются), далее:

```
facility_index  client_index  cost  preference
```

Незанятые ячейки матриц `c` и `d` — ноль.

## Переменные

| Имя | Смысл |
|-----|-------|
| `V`   | порог (бюджет) задачи верхнего уровня |
| `p`   | количество открываемых предприятий |
| `n`   | мощность множества предприятий |
| `m`   | мощность множества клиентов |
| `c`   | матрица производственно-транспортных затрат (n×m) |
| `d`   | матрица предпочтений клиентов (n×m) |
| `y`   | бинарный вектор размещения (n,) — решение верхнего уровня |
| `x`   | матрица назначений клиентов (n×m) — решение нижнего уровня |
| `rho` | матрица радиусов пороговой устойчивости (n×m) |

## Описание алгоритма

### Постановка

- **Верхний уровень (leader)** выбирает, какие предприятия открыть — бинарный вектор `y` с ровно `p` единиц. Цель — максимизировать радиус пороговой устойчивости `rho` при ограничении бюджета `V`.
- **Нижний уровень (follower)** при заданном `y` распределяет каждого клиента по открытому предприятию с минимальным «расстоянием» из матрицы `d` — матрица `x`.

Целевая функция: `V - f`, где `f = sum(c[i][j] * x[i][j])`.

### Пайплайн

```
generate_y_start(n, p)
        →
  y (стартовое размещение)
        →
  local_search(y)          # цикл 1-swap до локального оптимума
        →
  r (локальный оптимум)
        →
  improve(r)               # просмотр 2-swap
        →
  s (улучшенное решение)
        →
  s_rho > r_rho?
    да  → solve = s, повтор local_search
    нет → остановка
```

### Окрестности

- **1-swap** (`swap(y)`): одна единица → один ноль. Размер: `p * (n - p)`.
- **2-swap** (`swap_2(y)`): две единицы → два нуля. Размер: `C(p,2) * C(n-p,2)`.

### Дополнительно: две модели решения верхнего уровня

- **`leader`** (mode="full"): `rho[i][j] = x[i][j] * (V - f) / C` — распределённый радиус по всем назначениям.
- **`leader_simplified`** (mode="simplified"): весь `V - f` ставится в одну ячейку — позицию глобального min `c` среди назначенных.

Переключение: `python main.py --simplified`.
